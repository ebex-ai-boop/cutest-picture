# Cutest Picture — make.fun entry (cutest-picture-01)

Four baby animals in pajamas having a tea party on a fluffy pink rug:
a bunny, a kitten, a panda and a Pomeranian, with teacups, bear
cookies and sticker books. Generated by the entrant and resized to
1024×1024.

`main.py` (Python 3.13, standard library only) copies the picture held in
this repository (`entry.jpg`, 1024×1024 JPEG, 196,309 bytes) to
`/output/entry.png`. The program is deterministic: running it twice writes
byte-identical output.

## Run locally

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
