# Cutest Picture — make.fun entry (cutest-picture-01)

A fluffy grey-white kitten with huge green eyes, its head tilted
to the side in a playful look, hugging a big colourful plush fish
in both paws. Generated by the entrant with Stable Diffusion XL
on their own PC and saved as a 1024×1024 JPEG.

Round 4 replaces the round-3 yarn kitten: the yarn kitten scored
84.46% in the dev heats with no match lost, but the judge's own
notes said the duckling and chick beat it on charm — "head tilt,
rosy cheeks, and a tiny red scarf — a small story in one pose —
while A's yarn ball is sweet but more generic" — and the hedgehog
won because its strawberry grip was "a delightful story moment".
This entry answers that directly: a real head tilt, and a story
prop with a genuine hug — a kitten holding a smiling plush fish,
the composition the cutest-cat winner used — with a cleanly
rendered mouth and smooth fur with no stray tufts. One kitten,
one plush fish, readable at a glance.

`main.py` (Python 3.13, standard library only) copies the picture held in
this repository (`entry.jpg`, 1024×1024 JPEG, 133,833 bytes) to
`/output/entry.png`. The program is deterministic: running it twice writes
byte-identical output.

## Run locally

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
