# Cutest Picture — make.fun entry (cutest-picture-01)

A fluffy grey-white kitten with huge green eyes and an open-mouth
smile, holding a big red yarn ball in both paws, against a flat
pink background. Generated by the entrant with Stable Diffusion XL
on their own PC and saved as a 1024×1024 JPEG.

Round 3 replaces the round-2 scarf kitten: the scarf kitten scored
78.45% in the dev heats, and the judge's own notes said its mouth
looked "slightly smeared", its fur had "stray hair wisps" and a
"smudgy knit texture", and the pom-pom "reads oddly detached". This
entry answers that directly: a cleanly rendered mouth, smooth fur
with no stray tufts, and a story prop the kitten actually holds in
both paws — one kitten, one yarn ball, one flat background,
readable at a glance.

`main.py` (Python 3.13, standard library only) copies the picture held in
this repository (`entry.jpg`, 1024×1024 JPEG, 164,367 bytes) to
`/output/entry.png`. The program is deterministic: running it twice writes
byte-identical output.

## Run locally

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
